# Documentation, Code Notes, and Content Language Rule

1. **Code Files:** All text written as comments, notes, docstrings, JSDoc annotations, or explanatory blocks inside any source code file must strictly be written in neutral English.
2. **Text & Documentation Files:** All documentation and text files, including Markdown (`.md`), plain text (`.txt`), and structured documentation in `docs/` or `.agents/`, must strictly be written in English without exception.
3. **Git & Commit Messages:** All commit messages, branch descriptions, and changelog records must strictly be written in English.
4. **In-App Strings:** All default user-facing strings, logs, and system messages generated within the application must strictly be authored in English.
